# Data Science with Python internship

## Week 1 Task – Data Acquisition, Cleaning, and Preprocessing

This repository contains the work completed for Week 1 of my Logistics Data Analyst Internship.

### Objective

The objective of this task was to acquire a public dataset and perform data exploration, quality assessment, cleaning, and preprocessing to prepare the data for further analysis.

### Dataset

The dataset used for this task is the **Titanic Dataset (`train.csv`)**.

The dataset contains information about passengers, including variables such as:

- Passenger class
- Sex
- Age
- Number of siblings/spouses
- Number of parents/children
- Fare
- Port of embarkation
- Survival status

### Work Completed

The following data preparation steps were performed:

1. Data acquisition from a public dataset source
2. Initial data exploration
3. Examination of data types and structure
4. Missing-value assessment and treatment
5. Duplicate-record detection and handling
6. Detection of inconsistent or unusual entries
7. Outlier detection using box plots and the IQR method
8. Creation of a `CabinAvailable` feature
9. Removal of unnecessary columns
10. Categorical-variable encoding
11. Final data-quality checks

### Files Included

- `data_analysis_week1.py` – Python code used for data exploration, cleaning, and preprocessing
- `week1 data analysis.docx` – Detailed Week 1 report

### Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Conclusion

The data cleaning and preprocessing steps were performed to improve the quality and usability of the dataset for further data analysis and modelling.
